# 原创动画 MV

在当前仓库完成“原创词曲 → 本地伴奏与授权歌声 → SVG 动画 → 同步预览/视频”。保留用户选择的主题、时长、画幅和风格；《下班还有几厘米》是现有示例，不是所有新任务的模板内容。

## 项目入口

本技能依赖完整仓库，单独复制 `SKILL.md` 不会带走推理脚本、动画或模型。技能目录 `.agents/skills/create-original-mv/` 上溯三层是项目根；先通过 `package.json`、`src/Root.tsx` 和 `scripts/` 确认位置。

- 主合成：[`src/Root.tsx`](../../../src/Root.tsx) 中的 `OffWork`。
- 动画和音轨：[`src/MV/OffWorkMV.tsx`](../../../src/MV/OffWorkMV.tsx)，角色/道具在同目录的 `Characters.tsx`、`World.tsx`。
- 伴奏与乐谱生成：[`scripts/compose-music.py`](../../../scripts/compose-music.py)。
- 中文歌唱推理：[`scripts/render-qixuan.py`](../../../scripts/render-qixuan.py)。
- 模型、环境、谱面格式、重建命令及许可细节：执行相关步骤前读取 [references/workflow.md](references/workflow.md)。

## 制作流程

1. **确定创作范围。** 阅读当前代码与用户要求，复用工程结构；从零编写词曲、角色和分镜，外部字体/声音资源按许可使用。使用者明确选用已有作品时，先核实相应授权。
2. **先打开预览。** 从项目根运行 `npm run dev`，打开终端实际打印的 Studio URL，保持预览以便检查。需要原本机端口时可用 `npm run dev -- --port=3333`，不要把端口当作固定约束。
3. **写谱再出音。** 用逐字歌词、拼音、MIDI 音高、起始拍与时长编排乐谱；生成原创电子伴奏，再用绮萱 DiffSinger 模型生成中文歌声。新曲时长或结构变化时，同时修改脚本中的谱面范围、歌声分句、字幕和合成长度，不能只替换歌词文本。
4. **制作画面。** 使用原创 SVG 形状和 React 组件；动作由 `useCurrentFrame()` 和帧率计算，场景用 `Sequence` 编排。不要依赖 CSS 动画或真实时钟。给每个场景明确的动作/叙事变化，避免长时间只有静态标题。
5. **挂载歌声并同步。** `@remotion/media` 的 `<Audio>` 通过 `staticFile()` 读取 `public/audio/`。需要演唱的版本默认挂载歌声音轨；保留音频中的前奏静音，两轨从同一时间轴起点播放，避免再延迟一次。音量是各轨倍率，不是总和必须等于 1 的比例。
6. **检查并交付。** 先检查 Studio 的歌声音轨、播放/静音/音量状态和关键帧。用户要求导出或交付 MP4 时再渲染。交付说明区分已生成、已数值验证和已主观试听的事实。

## 授权与本地资源边界

- 当前中文音色为 **绮萱 v2.7.0**，使用 DiffSinger 技术和 OpenVPI PC-NSF-HiFiGAN 2025.02 声码器。模型在本机 CPU 推理；这条路线不需要付费生成接口。
- 公开发布时在明显位置标注 **“AI 合成歌声：绮萱 · DiffSinger”**，保留官方使用条款。声库、声码器权重、字体和程序各有独立许可；开源代码许可不能替代声库输出许可。
- 本项目的模型完整包及解压目录保存在 `models/` 并排除 Git。只发布代码、许可记录与允许使用的合成音频；不把模型权重、声库角色画像或虚拟环境加入 Git。后续若用户明确要求分发模型，应重新核对完整原包的再分发条款。
- 使用原始授权模型，不转换、修改、微调或拆分权重；不使用来源不清的歌手克隆模型。更换音色或版本时重新核实许可，不沿用绮萱的授权结论。
- 独立创作和许可记录不等于零版权风险；记录实际资源，不作绝对无侵权承诺。
- 制作 MV 不自动授权 Git 推送、公开发布、付费调用或向外部服务上传素材。相关动作以当前会话的用户授权为准。

## 验收要点

- `npm run lint` 通过；关键场景、字幕和片头/片尾署名可读。
- 音轨与合成时长一致，每句歌声非静音，字音/音符覆盖谱面，波形无削波。
- 如本次已导出，检查成片的实际音频，确认歌声已混入，而非只确认文件有一个音轨。可提取音频与人声源试听或比对。
- 模型 SHA256 与脚本中的官方原版记录一致；Git 暂存区中没有 `models/`、`.venv-audio/`、缓存或密钥。
